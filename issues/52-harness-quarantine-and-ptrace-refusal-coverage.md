No harness path (`ralph-loop.sh` run outside the sandbox with `RALPH_PUSH_REMOTE` set, the batch, the Lead driver) pushes a `rejected/*` or `refs/ralph/*` ref unless both hold for that run: the operator explicitly authorized it for that run (never a persistent default, a config file or an environment variable carried over from an earlier run), and a sensitive-data inspection of exactly the commits to be pushed passed (credential patterns, connection strings, `.env` and `.github/` files). Tests use a real bare remote and assert the refs it received: no quarantine ref without authorization; none with authorization when the commits hold a planted credential or a `.github/workflows` file; one only with authorization and a passing inspection.
